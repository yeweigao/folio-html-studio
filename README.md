# Folio HTML Studio

在浏览器中对 HTML 手册做可视化调整。React + TypeScript + Vite，纯静态部署，不需要账号、数据库或服务器上传接口。

## 本地运行

Node.js 22.x（建议 22.12 或以上的 22.x 版本）：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。先试内置三页示例，或导入自己的 `.html` / `.htm` / `.zip`。

## 当前功能

- 自动识别 `.page` 分页；普通 HTML 作为一个长画布。
- 点击选择文字、图片、SVG 和简单色块；支持本页对象列表。
- 提取页面的排版网格：优先使用页面级 CSS 网格，否则按版心（内容边距）、六栏栏间与正文行高生成栏线和基线，并叠加显示；内容表格自身的网格不会混入版面网格。拖动、尺寸手柄吸附到栏线/基线及附近对象的边缘与中线，移动时显示对齐辅助线，Alt 临时自由移动。
- 双击修改富文本；字体、字号、行距、颜色、对齐和背景设置。
- 左 / 中 / 右 / 两端对齐（末行自然对齐）；独立选择 auto / pretty / balance 断行，可批量应用并随 HTML 保存。pretty 优化段落断行，balance 平衡短标题行长；具体效果依浏览器实现而异。
- 文档内嵌字体始终保留在菜单中，并可恢复每个对象导入时的原字体。
- 9 组中英文印刷字体，选择时按需加载，下载 HTML 时内嵌字体与完整 OFL 授权；详见 [字体与授权清单](FONT_SOURCES.md)。
- 本页/全册同类样式、全册同字体、全册同字号批量应用；显示影响数量和页码，以共享 CSS 规则保存，保留原始样式表。位置和页面框尺寸只作用于当前对象。
- “同类样式”按对象类型、标签和原有类名分组；不是对任意 CSS 级联语义的自动推断。应用前可查看匹配类名和示例。
- 品牌暗纹 / SVG 可通过画布或本页对象筛选选中，调整透明度、颜色、缩放、旋转和母形替换。成对的跨页暗纹可选择一起调整。
- 替换图片，调整铺满/完整显示和九点裁切位置。
- 撤销与重做；修改自动保存在此浏览器的 IndexedDB，刷新后可恢复。
- 下载修改后的 HTML，保留对象标识与覆盖样式，可重新导入继续修改。
- 浏览器打印 / 另存为 PDF，打印时显示整册并隐藏编辑控件。
- ZIP 导入会内嵌本地 CSS、图片、字体及脚本资源；资源不齐时明确提示。

文件在浏览器本地读取，不传到本站服务器。文档中的远程图片、字体和样式仍可能联网加载。编辑文档放在不共享源的 sandbox iframe；内部脚本不能读取编辑器、IndexedDB 或其他文档，网络接口与嵌套框架被限制。外链脚本不会执行；需要的脚本请随 ZIP 打包，或使用单文件 HTML。

## Vercel 部署

将这个目录作为独立 Git 仓库导入 Vercel：

| 配置             | 值              |
| ---------------- | --------------- |
| Framework preset | Vite            |
| Build command    | `npm run build` |
| Output directory | `dist`          |
| Node.js          | 22.x           |
| 环境变量         | 无              |

项目已提供 `vercel.json`。也可在此目录运行 `vercel` 创建预览部署。部署不是本地构建的一部分；当前目录不会自动创建远端仓库或发布网站。

## 验证

```bash
npm run build
npx playwright install chromium
npm test
```

浏览器集成测试覆盖真实鼠标拖动与缩放、改字、撤销重做、下载重开、本机恢复、ZIP 资源、普通 HTML 和编辑器隔离。可选地用实际手册执行同一轮导入/修改/重开检查：

```bash
FOLIO_TEST_HTML=/absolute/path/to/handbook.html npm test
```

测试自行启动 Vite，默认使用 Chromium。测试截图及临时下载保存在忽略的 `.qa/` 下，不把客户素材加入项目。

## 与 handbook-designer 联动

handbook-designer 用 `node hb/core/cli.mjs folio-pack <项目>` 导出编辑包（单文件 HTML，带 `hb-build` / `hb-lang` 构建标记）。在这里导入后：

- 顶栏显示「基于构建 xxx · 语言」；
- 选中没有内容 ID / 编辑 ID 的对象时，右侧提示哪些修改不会写回手册源文件；
- 修改完照常「下载 HTML」，交回后由 `node hb/core/cli.mjs folio-sync <项目> <下载的 HTML>` 写回作者源（改字、换图、位置与样式；源文件在导出后被改过的地方报冲突，不覆盖）。

文件仍只在浏览器本地处理，不上传服务器。

## 当前边界

优先面向固定画布和 `handbook-designer-skill` 生成的 HTML，并不是任意网页的无损转换器。

- 修改保存到 HTML；手册源文件的写回由 handbook-designer 的 `folio-sync` 完成（见上节）。
- 拖动调整使用持久样式覆盖；大幅增加正文后仍应检查相邻内容，不会自动重新分页。
- 多选组合、跨页联合编辑、增加/删除页面、多人协作及服务器生成 PDF 尚未实现。
- ZIP 有多个 HTML 时优先选 `book.html`，再选 `index.html`；可单独打包其他 HTML。
- 本机草稿只保存最近一份文档，不能替代下载备份。
- 批量排印修改后需要检查受影响页面，当前不会自动重新分页。内置字体库提供常规 / 粗体，不包含完整斜体系列。
- SVG 支持整体及暗纹母形编辑，不是路径节点绘图工具。暗纹母形替换保留原有页面框与遮罩，并把输入作为单色图形处理；替换仅作用于当前对象。
- PDF 由浏览器打印生成。选择正确纸张、开启背景图形并关闭页眉页脚；不等同于原手册引擎的印前验收。
